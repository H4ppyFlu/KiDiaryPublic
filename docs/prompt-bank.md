# Prompt bank (seed)

The twenty German prompts Kidiary ships with. This file is the source of truth for the seed; `PROMPT_BANK` in `backend/app/seed.py` copies it, and the two are kept in step by hand (ADR-0004: the bank is seeded, not edited from inside the app).

All prompts are free-text (no tap-choice prompts in v1) and deliberately avoid gendered pronouns, so they read correctly for any child — and for a second child later.

**Rewrite these in your own voice.** They are a starting point to react to, not a finished set.
