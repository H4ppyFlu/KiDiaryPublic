# Kidiary

## Working in this repo

Run and test through Docker Compose; there is no local Python environment. The commands for
the stack, the tests and frontend development are in `README.md`.

A ticket is done when each of its acceptance criteria has been run and observed, not read.
Record the evidence as a comment on the issue, then close it.

## Agent skills

### Issue tracker

Issues live as GitHub issues in `H4ppyFlu/KiDiaryPublic`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, using the default label strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
